# Проекты по анализу данных

Учебные проекты по анализу и прогнозированию временных рядов на Python.

**Автор:** Ксения Юсупова, Прикладная информатика, РУДН.

| Проект | Что внутри | Инструменты |
| --- | --- | --- |
| [Прогноз недельных продаж Walmart](02-walmart-sales-forecast/) | Сравнение пяти моделей прогноза. Лучшая на 28% точнее базового прогноза | pandas, statsmodels, pmdarima, scikit-learn |
| [Визуальный анализ временного ряда цены](01-time-series-price-analysis/) | Очистка данных, тренд, сезонность, скользящее среднее, выводы | pandas, matplotlib, statsmodels |

Каждая папка содержит ноутбук с кодом, графиками и выводами, а также README с кратким описанием.

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook
```
